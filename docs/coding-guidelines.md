# Coding Guidelines

## Naming

Component: PascalCase
ex: UserCard.tsx

Function: camelCase
ex: getUser()

Variable: camelCase
userName

Constant: UPPER_CASE
ex: API_URL

## Folder

Satu Component 1 Folder Bila Kompleks

## Typescript

- Hindari tipe any
- Gunakan Interface/type
- Aktifkan strict mode

## React

- Gunakan Functional Component
- Pisahkan UI dan Business Logic
- Gunakan Custom Hook Bila Logika Dipakai Ulang

## Git

Prefix

feat: (feat:add login page)
fix: (fix: fix bug at line 30)
docs: (docs: update PRD.md)
style: (style: reformat code)
refactor: (refactor: simplify function)
test: (test: add fetch user test)
chore: (chore: update dependencies)
perf: (perf: improve query speed)

## Format

- Gunakan Prettier
- Gunakan ESlint
