### 1. Nama Proyek

AI Generator Quiz

### 2. Tujuan

Membantu Pengguna Untuk Mempelajari/Memahami Materi Dengan Quiz.

### 3. Target User

- Pengajar
- Mahasiswa
- Pekerja

### 4. Fitur

- Upload PDF (only)
- Diskusi Dengan AI apa isi dari dokumen

### 5. User Flow

```
Home
 |
Upload PDF
 |
AI Generate Quiz/Diskusi Dengan AI
```

- NEXTJS + EXPRESSJS Typescript Base
- Tailwind CSS
- Mongo DB

### 7. Non-Functional Requirements

- Responsive
- Loading < 2 detik

### 8. Future Features
